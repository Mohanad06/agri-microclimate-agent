# UI/UX Pro Max Skill

## Overview
The `ui-ux-pro-max` skill provides comprehensive design intelligence for building modern, high-contrast, aesthetically pleasing web user interfaces.

## Design System Guidelines

### 1. Color Palettes & Aesthetics
- **Dark Mode First**: Use rich dark backgrounds (e.g. `#0b0f17`, `#111827`, `#1e293b`) with glassmorphism overlays (`backdrop-filter: blur(12px)`).
- **Vibrant Accent Colors**:
  - Primary Cyan/Sky: `#0ea5e9`
  - Success Emerald: `#10b981`
  - Warning Amber: `#f59e0b`
  - Danger Rose: `#ef4444`
- **Contrast & Hierarchy**: Muted text in `#94a3b8`, primary headings in `#f8fafc`.

### 2. Typography Pairings
- **Headings & Primary Text**: Inter, Outfit, or Roboto (Google Fonts).
- **Data & Numeric Displays**: JetBrains Mono or tabular nums for metric values.

### 3. Component Patterns
- **Glass Cards**: `background: rgba(30, 41, 59, 0.6); border: 1px solid rgba(255, 255, 255, 0.1); border-radius: 12px;`
- **Interactive Badges**: Rounded status pills with semi-transparent background badges.
- **Micro-Animations**: Hover scaling (`transform: translateY(-2px)`), transition durations of `200ms ease-in-out`.
- **Accessibility**: High contrast ratio, descriptive `aria-label` attributes, and clear focus states.
